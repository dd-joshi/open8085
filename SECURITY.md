# Security Policy

## Supported versions

Open8085 Lab currently develops from the `main` branch and does not publish
long-term support releases.

| Version | Supported |
| --- | --- |
| Current `main` branch | Yes |
| Older commits or unofficial forks | Best effort |

## Reporting a vulnerability

Do not disclose a suspected vulnerability in a public issue, discussion, or
pull request.

Use GitHub's private vulnerability reporting option from the repository's
**Security** tab. Include:

- A clear description of the issue
- The affected page, feature, or file
- Reproduction steps or a minimal proof of concept
- The expected security impact
- Any suggested mitigation

If private vulnerability reporting is not enabled, open a public issue that
only asks the maintainer to establish a private contact channel. Do not include
exploit details or sensitive information in that issue.

The maintainer will acknowledge a complete report when practical, investigate
it, and coordinate a fix before public disclosure.
